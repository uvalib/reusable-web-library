# Migration

The migration guide lives with the agent skill so there is a single copy: [skills/uvalib-web-components/reference/migration.md](../skills/uvalib-web-components/reference/migration.md). It maps the old `/web-components/latest/...` and `/web-components/cdn-vX.Y.Z/...` URLs and the old `@uvalib/<pkg>` npm names to the new `@uvalib/web-components` equivalents. See [usage](usage.md) for installing the skill.
